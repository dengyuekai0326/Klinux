钢球控制系统：上位机—下位机串口通信协议
版本：V2（上位机只发送小球状态、接收录像控制）

一、串口参数

波特率：115200
数据位：8
停止位：1
校验位：无
流控：无
字节序：多字节数据均为大端序（高字节在前）
负数编码：二进制补码


二、坐标和方向定义

水管中心为0，画面右侧为正，画面左侧为负。

上位机发送的X不是未经处理的摄像头像素坐标，而是经过水管左端、中心、
右端标定后得到的“归一化像素差/控制坐标”：

水管左端 -12.5 cm  <=> X = -320
水管中心   0.0 cm  <=> X =    0
水管右端 +12.5 cm  <=> X = +320

换算公式：

位置(cm) = X / 320 × 12.5
X = 位置(cm) / 12.5 × 320

第二问的三个关键位置：

-5.0 cm  <=> X = -128
 0.0 cm  <=> X =    0
+5.0 cm  <=> X = +128

如果下位机采用0.5 cm作为到达判定阈值：

0.5 / 12.5 × 320 = 12.8

可以取约±13个X单位作为判定范围，最终阈值由电控现场调试确定。


三、上位机发送小球状态

发送频率：有有效小球状态时，以30 Hz发送。
固定长度：6字节。

帧格式：

AA X_H X_L V A FF

字节0：0xAA，帧头
字节1：X_H，位置X的高字节
字节2：X_L，位置X的低字节
字节3：V，速度
字节4：A，加速度
字节5：0xFF，帧尾

1. 位置X

类型：signed int16
范围：-320～+320
字节序：大端序
含义：以水管中心为0，右正左负

下位机C语言解码示例：

int16_t x = (int16_t)(((uint16_t)rx[1] << 8) | rx[2]);

常用位置帧（V和A暂取0）：

-12.5 cm，X=-320：AA FE C0 00 00 FF
 -5.0 cm，X=-128：AA FF 80 00 00 FF
  0.0 cm，X=   0：AA 00 00 00 00 FF
 +5.0 cm，X=+128：AA 00 80 00 00 FF
+12.5 cm，X=+320：AA 01 40 00 00 FF

2. 速度V

类型：signed int8
范围：-128～+127
方向：正数表示向右运动，负数表示向左运动
单位：每个30 Hz控制周期移动的X单位

上位机计算方式：

V = round(X方向速度[单位/秒] / 30)

下位机C语言解码示例：

int8_t v = (int8_t)rx[3];

3. 加速度A

类型：signed int8
范围：-128～+127
方向：正数表示向右方向的加速度，负数表示向左方向的加速度
单位：按30 Hz控制周期缩放后的X加速度量

上位机计算方式：

A = round(X方向加速度[单位/秒²] / 30²)

下位机C语言解码示例：

int8_t a = (int8_t)rx[4];

超出字段范围时，上位机会进行饱和限制。


四、下位机控制录像

录像控制命令也是固定4字节：

开始录像：AA BB BB FF
停止录像：AA CC CC FF

说明：

1. 收到开始命令后，上位机在recordings目录创建带时间戳的MJPG AVI文件。
2. 重复发送开始命令不会重复创建文件。
3. 收到停止命令后，上位机停止并关闭当前录像文件。
4. 停止后再次开始，会创建一个新的录像文件。
5. 录像写盘使用独立线程。写盘速度不足时只丢弃最旧的录像帧，
   不阻塞视觉识别和30 Hz串口状态发送。
6. 录像控制命令当前没有ACK，是否成功可通过上位机终端日志或调试画面确认。


五、丢检和安全行为

1. 小球短暂丢检时，上位机会使用滤波后的速度做短时位置预测。
2. 当前发送预测上限为80 ms。
3. 最后一次有效测量超过150 ms后，上位机停止发送小球状态帧，不发送伪造坐标。
4. 建议下位机设置通信看门狗：超过200 ms没有收到完整有效状态帧时，
   停止或限制执行机构输出，进入安全状态。
5. 小球重新识别后，上位机会恢复30 Hz状态发送。


六、接收解析注意事项

1. 协议采用固定长度帧，上位机状态帧固定6字节，录像命令固定4字节。
2. 数据字段本身可能出现0xAA或0xFF，不能把遇到的第一个0xFF直接当作帧尾。
3. 找到0xAA后必须按照固定长度接收，并检查固定位置上的帧尾：
   状态帧检查第6字节是否为0xFF；
   命令帧检查第4字节是否为0xFF。
4. 如果固定位置帧尾不正确，丢弃当前帧头并重新寻找下一个0xAA。
5. 当前协议没有校验和、没有ACK，也不会发送任务状态帧。
6. 下位机收到X后独立完成全部模式的位置误差判断与闭环控制。
7. 除两条录像命令外，其他4字节命令均会被上位机忽略。


七、当前通信方向汇总

上位机 -> 下位机：
AA X_H X_L V A FF

下位机 -> 上位机（录像控制）：
AA BB BB FF  开始录像
AA CC CC FF  停止录像
